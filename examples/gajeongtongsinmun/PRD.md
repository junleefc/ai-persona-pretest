# PRD · 가정통신문 정리 랜딩페이지

1. 한 줄: 초등 저학년 맞벌이 부모에게, 가정통신문 사진을 보내면 일정과 준비물 정리표를 카톡으로 받는 무료 체험을 신청받는 페이지.
2. 볼 사람: 초등 1~2학년 자녀가 있는 맞벌이 부모.
3. 구성 (위에서 아래)
   - 첫 화면: 퇴근 후 통신문 읽다가 준비물 놓친 경험
   - 차이: 단톡방에 묻지 않아도 전날 저녁 카톡으로 온다
   - 무료 제안: 통신문 3장 보내면 정리표 하루 안에
   - 신청: 이름, 이메일, 아이 학년
4. 오늘 안 만드는 것: 결제, 로그인, 회원가입, 데이터 저장.
