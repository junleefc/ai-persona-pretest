# first-7-customers

**내 랜딩페이지를 가상 한국인 7명에게 보여주고, 신청 버튼을 누를지 물어보는 도구**

오늘 만든 페이지를 아직 아무도 안 봤습니다. 실제 고객을 만나기 전에, 통계 데이터로 만든 가상 한국인 7명에게 먼저 보여 주세요. 7명 중 몇 명이 누르는지, 안 누르면 어느 문장에서 멈췄는지, 그 문장을 뭐라고 바꾸면 되는지가 한 장으로 나옵니다. 그리고 바로 고칩니다.

Claude 데스크탑 앱의 Code 탭에서 프롬프트 하나만 붙여넣으면 됩니다. 설치할 것도, 외울 명령어도 없습니다.

## 3단계로 끝

준비물: 오늘 랜딩페이지를 만든 **mvp 폴더** 안에 기획서 md, PRD.md, index.html.

**1. 보여주기.** Code 탭에서 mvp 폴더를 연 뒤 붙여넣습니다.

```
https://github.com/junleefc/first-7-customers
이 리포의 GUIDE.md를 읽고 그대로 진행해줘.
이 폴더에 내 기획서 md, PRD.md, index.html이 있어.
가상 한국인 7명에게 내 페이지를 보여주고 신청 버튼을 누를지 물어봐줘.
다 되면 REPORT.html을 브라우저로 열어서 보여줘.
```

**2. 읽기.** REPORT.html이 열립니다. 맨 위 세 줄만 보면 됩니다. 7명 중 몇 명이 누르는지, 가장 많이 걸린 구간, 바꿀 문장 하나.

**3. 고치기.**

```
REPORT.md의 결론을 반영해서 index.html을 고쳐줘.
가장 많이 걸린 구간의 문장만 바꾸고, 나머지 내용과 디자인은 그대로 둬.
다 되면 브라우저에서 다시 열어서 보여줘.
```

고친 페이지로 다시 물어보는 프롬프트와 막혔을 때 대처는 [PROMPT.md](PROMPT.md)에 있습니다.

## 무엇을 물어보나

7명 각각이 기획서와 페이지를 읽고 1인칭으로 답합니다. 질문은 한 장 기획서의 다섯 칸과 같습니다.

| 질문 | 확인하는 것 |
|---|---|
| 불편 | 기획서에 적은 불편이 이 사람에게도 있나. 마지막으로 겪은 게 언제인가 |
| 지금 방법 | 지금은 어떻게 넘기고 있나. 얼마나 귀찮은가 |
| 차이 | "내 것은 이게 다르다"가 이 사람에게 의미 있나 |
| 가격 | 그 돈을 낼 것인가. 이미 돈 내고 쓰는 게 있나 |
| 페이지 | 페이지를 위에서 아래로 읽고 **버튼을 누르나**. 안 누르면 첫 화면 / 차이 / 무료 제안 / 신청 항목 중 **어디서 멈췄나**. **뭐라고 바뀌면 누르나** |

7명 중 5명은 기획서의 "누구"에 맞는 사람, 2명은 일부러 살짝 벗어난 사람입니다. 벗어난 2명이 "나 말고도 이 불편을 겪는 사람이 있나"를 알려 줍니다.

## 결과 예시

가정통신문 정리 서비스(초등 저학년 맞벌이 부모 대상, 월 4,900원)로 돌린 결과입니다. 전체는 [examples/gajeongtongsinmun](examples/gajeongtongsinmun)에 있습니다.

> **7명 중 3명이 신청 버튼을 누릅니다.** 2명은 안 누르고, 2명은 모르겠다.
>
> **가장 많이 걸린 곳: 첫 화면.** 안 누른 2명이 모두 "퇴근하고 통신문 읽다가, 내일 준비물을 또 놓치셨나요?"에서 멈췄다. 이유는 "준비물을 놓친 적이 없다"와 "아직 통신문이 안 온다".
>
> **바꿀 문장**
> 지금: 퇴근하고 통신문 읽다가, 내일 준비물을 또 놓치셨나요?
> 제안: 매주 서너 장씩 오는 가정통신문, 퇴근 후에 일정과 준비물만 골라서 보세요.
>
> **신청 항목.** 45세 휴대폰 매장 판매원 김병철 씨: "카톡으로 보내 준다면서 카톡 번호는 안 받고 이메일을 받네요." 이메일을 빼거나 왜 받는지 한 줄을 적어라.
>
> **근처 2명이 말해 주는 것.** 미취학 자녀 엄마는 안 눌렀고, 혼자 아이를 키우는 아빠는 눌렀다. "맞벌이 엄마"로 좁히지 말고 "혼자 챙기는 부모"까지 넓혀도 된다.

7명 카드 중 하나:

> **P7 · 한용진** 37세 남 · 창원 진해구 · 금속·재료 공학 기술자 · 자녀와 거주 · 근처 · 누른다
> 지금 방법: 하굣길에 아이한테 직접 물어봅니다. 엄마들 단톡방 같은 건 저한테 없어요. 물어볼 데가 없는 게 제일 귀찮습니다.
> 가격: 4,900원 냅니다. 치킨집 생맥주 한 잔 값이에요.
> 이렇게 바뀌면 누른다: "혼자 키우는 아빠도 쓰는 거라고 한 줄만 있으면 더 빨리 눌러요."

## 할 수 있는 것, 없는 것

**할 수 있는 것**
- 페이지의 어느 문장이 약한지 미리 찾기
- "이런 사람은 이런 이유로 안 누른다"는 반대 시나리오 보기
- 실제 사람에게 물어볼 질문 3개 얻기

**할 수 없는 것**
- 수요가 있다고 증명하기. 가상 고객이 누른다고 해도 실제 사람이 누르는 것과 다릅니다
- 가격이 맞다고 확정하기
- 실제 인터뷰 대체하기

**결과는 전부 가설입니다.** "된다"가 아니라 "이 문장을 고치고 실제 사람 3명에게 확인하자"로 읽으세요. 리포트 끝에 그 3명에게 물어볼 질문이 있습니다.

## 데이터: 가상 한국인 5,000명

NVIDIA가 공개한 **Nemotron-Personas-Korea**(100만 명의 한국인 합성 페르소나)에서 연령대·성별·권역이 고르게 섞이도록 5,000명을 뽑아 [personas.jsonl](personas.jsonl)에 넣어 두었습니다. 통계청, 대법원, 건강보험공단 등 실제 공공 통계를 바탕으로 AI가 만든 가상 인물이라 개인정보 문제가 없습니다.

한 사람마다 나이, 성별, 지역, 직업, 학력, 혼인, 가구 형태, 주거 형태와 함께 직업·가족·관심사·목표를 서술한 한국어 텍스트가 있습니다.

| 항목 | 내용 |
|---|---|
| 제작 | NVIDIA |
| 원본 | [huggingface.co/datasets/nvidia/Nemotron-Personas-Korea](https://huggingface.co/datasets/nvidia/Nemotron-Personas-Korea) |
| 라이선스 | CC BY 4.0 |
| 이 리포의 샘플 | 5,000명, 11MB, 추출 방법은 [scripts/build_sample.py](scripts/build_sample.py) |

5,000명인 이유: 깃허브에서 바로 받을 수 있는 파일 크기(20MB 이하)와, 타깃을 좁게 잡아도 후보가 나올 만큼의 인원 사이에서 정한 숫자입니다. 연령대 6 × 성별 2 × 권역 5의 60개 집단에서 원본 비율대로 뽑되 각 집단 최소 30명을 보장했습니다(층화 추출). 자녀 학년, 배우자 취업 여부처럼 원본에 없는 정보는 인원을 늘려도 나오지 않습니다.
